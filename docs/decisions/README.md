# Architecture Decision Records

ADR ghi lại quyết định kỹ thuật có ảnh hưởng đáng kể để chính tác giả và cộng tác viên tương lai hiểu cả kết quả lẫn lý do.

Tên file: `NNNN-ten-ngan-gon.md`.

Mẫu:

```md
# Tiêu đề

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

Vấn đề cần quyết định.

## Decision

Phương án được chọn.

## Consequences

Lợi ích, hạn chế và ảnh hưởng.
```

Không sửa lịch sử của một ADR đã được thay thế; tạo ADR mới và liên kết ADR cũ.
