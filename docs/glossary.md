# Thuật ngữ

| Thuật ngữ | Nghĩa trong dự án |
| --- | --- |
| Customer | Người dùng mua hàng |
| Admin | Người dùng có quyền quản trị |
| Contract | Cấu trúc request/response được FE và BE thống nhất |
| Feature | Nhóm chức năng phía frontend theo nghiệp vụ |
| Module | Biên nghiệp vụ phía backend |
| ADR | Bản ghi quyết định kiến trúc |
| Source of truth | Nơi chính thức phải được cập nhật khi thông tin thay đổi |

Bổ sung thuật ngữ nghiệp vụ tại đây khi nhóm thống nhất để tránh dùng nhiều tên cho cùng một khái niệm.
