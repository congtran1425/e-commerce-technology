# Database schema

Database và ORM chưa được chọn.

Sau khi chốt công nghệ, migration của ORM là nguồn sự thật có thể thực thi. File này giải thích entity, quan hệ, constraint quan trọng và lý do thiết kế; không sao chép toàn bộ schema theo cách dễ bị lệch khỏi migration.

Mọi thay đổi schema phải đi kèm migration, cập nhật tài liệu và đánh giá ảnh hưởng đến API.
